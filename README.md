# Prijsvergelijker

Prijslijsten van leveranciers inladen, vergelijken en facturen maken.

    npm install
    npm run dev        # http://localhost:5173
    npm run build      # statische versie in dist/

Gegevens staan in de browser (IndexedDB). Maak back-ups via Instellingen.
`npm run test:import -- bestand1.xlsx bestand2.xlsx` test de kolomherkenning op echte prijslijsten.
